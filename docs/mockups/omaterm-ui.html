Status icons: spinning arc = working · arc filling up = progress · amber ring with pulsing dot = needs you · red "!" = failed · filled check = done, unread · ✕ = exited · no icon = idle shell
Footer chips: counts of sessions that need you, are working, or are done. Click one to jump to the next such session (Ctrl+Shift+J for "needs you").
Pane header: status or program logo, title, cwd, git chip (branch +added −removed), status chip. Controls appear on hover. Drag the title to move or swap panes.
Theme: every color here is derived from the Omarchy theme. Switching the Omarchy theme recolors the app live.
